# Hafızım
Çevrimdışı çalışan hafızlık ve müteşabihat asistanı (PWA + Capacitor).

## APK nasıl alınır (bilgisayarsız, sadece GitHub)
1. GitHub'da yeni repo aç, zip içindeki **tüm dosyaları** (`.github` klasörü dahil) yükle.
2. **Actions** sekmesi → "APK Derle" çalışır (~5 dk).
3. Bitince çalıştırmanın altındaki **Hafizim-APK** dosyasını indir, zip'ten çıkan `app-debug.apk`'yı telefona kur.

## Logo
`www/icons/icon-192.png` ve `icon-512.png` dosyalarını kendi logonla (aynı adla) değiştir.

## Notlar
- Her sayfa/ses/meal ilk açılışta internetten iner, sonra çevrimdışı çalışır (ses dosyaları hariç, dinlenen ayetler önbelleğe alınır).
- Müteşabihat için ilk kullanımda tüm Kur'an bir kez indirilir.
- Veriler cihazda saklanır; Liste sekmesinden yedek alabilirsin.
